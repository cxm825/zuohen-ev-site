# 全站接入 Google Analytics 4

直接内嵌官方 gtag.js 代码段（不用 GTM，简单站点无需引入标签管理层）。衡量 ID 先用占位符 `G-XXXXXXXXXX`，你拿到真实 ID 后全局替换即可。

## 改动内容

### 1. 11 个静态页面注入 GA4 代码段
在以下文件的 `<head>` 开标签之后插入标准 GA4 代码段（async 加载 gtag.js + inline config）：
`public/` 下的 index.html、products.html、product.html、solutions.html、news.html、about.html、company-profile.html、certifications.html、cases.html、contact.html、404.html

```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

- 实现方式：写临时 `.mjs` 脚本批量插入（遵守你的全局约定：临时 Node 脚本走 Bash 执行，完成后删除），脚本需**保留 UTF-8 BOM**、兼容单行压缩格式的页面（about/products/product/solutions/contact）
- 跳过 `product/index.html`、`products/index.html` 两个纯跳转页（location.replace 立即跳走，埋码只会造成重复计数）
- 404 页也埋（可统计死链来源）

### 2. 动态新闻页注入（一处改动全覆盖）
`src/news.js:16` 的 `layout()` 模板函数 `<head>` 中加入同样代码段——同时覆盖 `/news` 列表、所有 `/news/{slug}` 文章页、15 个 legacy `/*.html` 新闻路径、新闻 404。

### 3. 询盘转化事件 generate_lead
- `public/contact.html:50`、`public/index.html:80` 的表单成功回调（`setStatus('Thank you — ...')` 处）追加：
  ```js
  if (typeof gtag === 'function') gtag('event', 'generate_lead');
  ```
- 之后你在 GA4 后台「事件」里把它标记为关键事件（转化）即可看询盘转化率

### 4. 不埋码的部分
admin 后台（`src/inquiries.js` 的 adminShell/loginPage，noindex 内部页面）。

### 5. README 加一行部署提醒
说明部署前需把 `G-XXXXXXXXXX` 全局替换为真实 GA4 衡量 ID（出现在 12 个文件中）。
